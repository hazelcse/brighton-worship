# Brighton Worship

- Fonts are the owner's choice: read [FONTS.md](FONTS.md) before touching any font, font weight
  or `font-*` class. Don't change them as a side effect; if a change needs one, ask first or say
  so plainly in your summary.
- Layout measurements are the owner's choice too: read [LAYOUT.md](LAYOUT.md) before changing the
  page or nav width, padding or the roster landing page's card sizes. Same rule: ask first, or
  say so plainly. `node web/scripts/check-layout.mjs` checks them.
- [PAGE-LAYOUTS.md](PAGE-LAYOUTS.md) describes how every page is laid out (widths, toolbars, card
  grids, what changes on phones). Read the page's section before changing its layout, follow its
  shared patterns for new pages, and update it when a layout changes.
